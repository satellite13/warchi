# История изменений

Все значимые изменения проекта документируются в этом файле.

## [Unreleased]

## [0.5.1] - 2026-03-31

### Добавлено
- Расширена встроенная справка и `docs/composite-components.md` по настройке composite-компонентов в редакторах моделей и нотаций (EN/RU/FR).

### Изменено
- Атрибуты нотации: более надёжный разбор и нормализация `compositeShapeType` по списку допустимых фигур composite.

## [0.5.0] - 2026-03-31

### Добавлено
- Полноценный редактор composite-компонентов в сценариях нотаций: типы компонентов, инспекторы по типам, полный shape picker и property-based UI для стилей/биндингов вместо raw JSON patch.
- Биндинги composite в редакторах нотаций и моделей: текстовые элементы можно привязывать к имени узла/кастомным свойствам, а привязки иконок нотации корректно резолвятся в палитре модели.
- Расширенные настройки меток связей в диаграммах нотаций: позиция метки вдоль пути, режим follow-path, многострочные метки через `\n` и улучшенная поддержка style bindings.

### Изменено
- Переработаны composite-панели и UX дерева в редакторе нотаций: более ясная визуальная иерархия, человекочитаемые имена компонентов и согласованность с node/style панелями.
- В редакторе модели для composite-элементов добавлена вкладка стиля и действия восстановления стиля из нотации там, где это применимо.

### Исправлено
- Поведение edge style в редакторах нотаций/моделей: корректное применение `labelInset` для новых связей, явный `markDirty` после изменения inset, fallback-стили нотации для diagram-only связей.
- Точность composite preview/runtime: контуры custom-shape, рамки контейнеров, scroll-поведение, действия для неудаляемых узлов дерева и ограничения структуры дерева.

## [0.4.6] - 2026-03-27

### Добавлено
- Локаль интерфейса FR по приложению; переключатель языка на лендинге (RU/EN/FR) согласован с локалью внутри приложения.
- Пользовательская документация на французском (`*.fr.md`) и французский changelog (`CHANGELOG.fr.md`) для справки и блока новостей на главной.
- Скрипт `scripts/build-models-fr.mjs` и сгенерированный `models.fr.generated.ts` для строк редактора моделей.

### Исправлено
- `CHANGELOG.ru.md`: восстановлена отсутствующая секция `## [0.0.27]` для соответствия английской истории версий.

## [0.4.3] - 2026-03-25

### Добавлено

## [0.4.2] - 2026-03-25

### Добавлено

### Изменено

### Исправлено

## [0.4.1] - 2026-03-25

### Исправлено
- Кастомные выпадающие списки (поиск и множественный выбор) не выходят за границы окна: ниже середины экрана панель открывается вверх, высота ограничивается доступным местом.

### Изменено

## [0.4.0] - 2026-03-25

### Добавлено
- Live sync модели на фронтенде: режимы `ws`, `poll`, `hybrid`, подписка по STOMP и резервный polling через переменные окружения.
- Блокировки редактирования диаграммы: взятие/снятие при работе с последней версией диаграммы, отображение держателя блокировки, админ-страница открытых блокировок.
- Разрешение конфликтов пакетного сохранения в Model Editor: сравнение полей, перезагрузка с сервера или принудительная перезапись, предупреждения по связям при необходимости.
- Панель трассировки: подсветка наличия связи на активной диаграмме; перетаскивание допустимой связи с панели на холст для размещения ребра.
- Защита доступности (availability guard) и согласованные сценарии входа/документации при недоступности API.

### Изменено
- Model Editor разбит на composable-модули загрузки, конвейера сохранения, подгрузки relations/rules нотации и слияния после перезагрузки.
- Редирект после авторизации: при входе сохраняется возврат на защищённый маршрут; после регистрации по-прежнему переход на главную.
- Обновлены пользовательская и техническая документация по live sync, блокировкам диаграммы, конфликтам сохранения и auth.

## [0.0.9] - 2026-02-22

### Добавлено

- UI шаринга по ACL для моделей, нотаций и типов с модальным окном управления доступами.
- Поддержка прав шаринга `VIEW` и `EDIT`, включая отображение фактического уровня доступа в списках.
- Страницы профиля пользователя и администрирования пользователей с нормализацией ролей (`ADMIN` / `USER`).
- Действие «Информация о диаграмме» в тулбаре редактора модели с показом нотации (имя/версия/владелец).
- Поддержка загрузки метаданных нотации через `/notations/{id}/meta` для диаграмм с недоступной нотацией.

### Изменено

- Убраны клиентские допущения о роли `EDITOR` в auth, роутинге и фильтрации сущностей.
- Редакторы моделей/нотаций/типов переведены на работу от ACL-ответов backend вместо owner-only фильтрации.
- Улучшены сообщения об ошибках API для случаев отозванного или отсутствующего доступа.

### Исправлено

- Серия регрессий сохранения в шареных сценариях (403/409) при редактировании моделей и нотаций.
- UX-проблемы шаринга при поиске пользователя и назначении доступа по умолчанию.
- Проблемы обрезания текста и высоты панели на главной странице.

## [0.0.8] - 2026-02-21

### Добавлено

- Составные метки для узлов диаграммы с шаблонами подстановки `${name}` и `${имяСвойства}`.
- Поддержка переноса строки `\n` в шаблонах меток для многострочного отображения.
- Управление выравниванием текста в метке (по левому / по центру / по правому) независимо от позиции метки.
- UI для редактирования шаблона метки в панели стиля и панели свойств с предпросмотром результата.
- Поддержка `editableText` в Papirus TextLabel для раздельного отображения и редактирования текста.
- Автоподстановка значений по умолчанию для новых обязательных свойств при загрузке модели.

### Изменено

- Обновлён Papirus до 0.3.6 с поддержкой выравнивания текста в метке.
- При двойном клике на узел для переименования отображается только имя компонента, а не результат шаблона.

### Исправлено

- Шаблон метки не копировался в инстанс при перетаскивании компонента из палитры.
- Метка на диаграмме не обновлялась при изменении значения кастомного свойства.
- Ошибка валидации при сохранении модели, если в нотации добавлены новые обязательные свойства.

## [0.0.5] - 2026-02-20

### Добавлено

- Переименование модели в заголовке редактора и в карточках каталога моделей.
- Валидация дублирования имени/версии при переименовании модели.
- Сохранение z-порядка узлов в атрибутах диаграммы (`attrs.zIndex`) для сохранения слоёв после переоткрытия.

### Изменено

- Логика наложения узлов: меньшие узлы отображаются поверх больших.
- При одинаковом размере выделенный узел поднимается выше остальных.

### Исправлено

- Ошибки сборки/линтинга в логике z-порядка диаграммы модели.

## [0.0.4] - 2026-02-19

### Добавлено

- Сохранение состояния сворачивания тегов в списке компонентов нотации между сессиями.
- Раздел с описанием текущей версии на главной странице из `CHANGELOG`.

### Изменено

- Метаданные нотации (название/версия) перенесены из левой панели в заголовок.
- Обновлены контролы левой панели нотации: компактные кнопки-иконки, сортировка рядом с поиском, счётчик элементов рядом с заголовком.
- Расширено пространство заголовка в редакторах моделей/нотаций для длинных имён.

### Исправлено

- Высота строки контролов списка компонентов: select сортировки больше не растягивает соседние кнопки.
- Состояние сворачивания секции тегов не сохранялось между сессиями.

## [0.0.3] - 2026-02-19

### Добавлено

- Контекстное меню для узлов и связей на диаграмме модели: удаление узла, переключение типа связи, удаление связи.
- Иконки типов связей в контекстном меню (`straight`, `polyline`, `bezier`).
- Управление количеством портов узла в панели стиля (`top`, `bottom`, `left`, `right`) с сохранением в `attrs.diagramStyle`.

### Изменено

- Кнопки действий панели стиля (восстановление из нотации, сворачивание) перенесены в заголовок секции «Фигура/Связь».
- Унифицирован внешний вид кнопок-иконок панели стиля с левой панелью дерева.
- Подтверждение при закрытии диаграммы с несохранёнными изменениями (`Сохранить / Не сохранять / Отмена`).

### Исправлено

- Перепривязка порта связи теперь активирует кнопку сохранения и корректно работает с undo/redo.
- Удаление связи с диаграммы теперь участвует в истории undo/redo.
- Применение пользовательского количества портов и точек привязки после переоткрытия диаграммы.

## [0.0.2] - 2026-02-19

### Добавлено

- Подтверждение удаления связи с выбором: удалить с текущей диаграммы или из модели целиком.
- Сворачиваемый блок стиля в правой панели редактора модели с быстрым восстановлением стилей из нотации.
- Валидация обязательных кастомных свойств перед сохранением для узлов и связей модели.

### Изменено

- Боковые панели редактора модели стали изменяемыми по размеру и сворачиваемыми.
- Улучшены метки диалога повторного использования связей: отображается тип и метка вместо ID.
- Редакторы кастомных свойств отрисовывают поля ввода по типу свойства (включая enum select).

### Исправлено

- Сохранение и повторное применение стилей связей после переоткрытия диаграмм.
- Обработка истории undo/redo при переключении или закрытии диаграмм.
- Инициализация значений по умолчанию кастомных свойств при добавлении узлов из палитры и привязке компонентов/отношений.
- Переключение диаграмм с несохранёнными изменениями: выбор сохранить/отменить и перезагрузка состояния.
