# История изменений

Все значимые изменения проекта документируются в этом файле.

## [Unreleased]

## [0.0.23] - 2026-02-28

### Добавлено
- Групповое перетаскивание в диаграмме модели: перетаскивание узла внутрь контейнера перемещает оба вместе.
- Автолинки в группах: при перетаскивании узла в контейнер с group-связью предлагает создать или использовать связь (настройка «Автолинки в группах» в параметрах диаграммы).
- Логика `isLinkOnDiagram()` и `tryCreateAutoLink()`: связь на диаграмме → без действия; связь есть вне диаграммы → диалог использования; связи нет → диалог создания.
- Отслеживание использования узлов в ModelTreePalettePanel.
- Флаг системного свойства (`system`) в CustomProperty для специального поведения в нотации (например, `group` для режима группировки).

### Изменено
- Редактор модели: модальные окна повторного использования существующей связи и выбора отношения для автолинков.
- Улучшена навигация с клавиатуры и управление фокусом в модальных окнах.
- Обновлён `@ngroznykh/papirus` до 0.3.21.

### Исправлено
- Системные свойства больше не отображаются в панели свойств редактора модели (ModelPropertiesPanel).
- Системные свойства исключены из проверки обязательных полей при сохранении (пользователь не может их редактировать).
