# Вклад в Warchi

Спасибо за интерес к проекту.

## Требования для разработки

- Node.js 18+
- npm 9+
- NPM-пакет Papirus (`@ngroznykh/papirus`)

## Локальный запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Проверки качества

Перед созданием pull request запустите:

```bash
npm run lint
npm run build
npm run test
```

Если менялся деплой:

```bash
helm lint ./charts/warchi
bash -n ./deploy.sh
```

## Ветки и Pull Request

1. Создайте feature-ветку от `master`
2. Делайте коммиты атомарными и сфокусированными
3. Добавляйте/обновляйте тесты при изменении поведения
4. Обновляйте документацию при изменениях в логике или эксплуатации
5. Открывайте PR с контекстом и тест-планом

## Рекомендации по коммитам

- Используйте чёткие заголовки в повелительном наклонении
- Поясняйте *зачем* внесено изменение
- Не смешивайте несвязанный рефакторинг и функциональные изменения

## Checklist для PR

- [ ] Локально проходят lint/build/tests
- [ ] Изменённые UI-сценарии проверены вручную
- [ ] Документация обновлена при необходимости
- [ ] В репозиторий не добавлены секреты или приватные данные

## Баг-репорты

Указывайте:

- ожидаемое поведение
- фактическое поведение
- шаги воспроизведения
- логи или скриншоты (если есть)
