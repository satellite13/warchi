# Чеклист подготовки к Open Source

Этот документ помогает подготовить `warchi` к публичному open-source релизу.

## 1. Легал и метаданные репозитория

- [ ] Выбрать лицензию (`MIT`, `Apache-2.0`, `GPL-3.0` и т.д.) и добавить `LICENSE`
- [ ] Проверить совместимость лицензий зависимостей
- [ ] Добавить описание репозитория, topics и homepage
- [ ] Указать контакты/мейнтейнеров

## 2. Security readiness

- [ ] Удалить/заменить небезопасные дефолты и приватные значения
- [ ] Проверить, что в репозитории нет секретов (`.env`, скрипты, values)
- [ ] Поддерживать `SECURITY.md` с приватным каналом репорта
- [ ] Проверить production-ожидания по окружению и деплою

## 3. Базовый комплект документации

- [x] `README.md` и `README.ru.md`
- [x] `CONTRIBUTING.md` и `CONTRIBUTING.ru.md`
- [x] `SECURITY.md` и `SECURITY.ru.md`
- [x] `CODE_OF_CONDUCT.md` и `CODE_OF_CONDUCT.ru.md`
- [ ] Добавить архитектурную схему (опционально)
- [ ] Добавить FAQ для публичных пользователей (опционально)

## 4. Quality gate (build/test)

- [ ] CI pipeline для lint/build/test на pull request
- [ ] Опционально: E2E проверки в CI
- [ ] Зафиксировать минимально поддерживаемые Node/npm версии

Рекомендуемый минимум для CI:

1. `npm run lint`
2. `npm run build`
3. `npm run test`
4. `helm lint ./charts/warchi`

## 5. Release process

- [ ] Зафиксировать политику версионирования и ритм релизов
- [ ] Поддерживать `CHANGELOG.md` и `CHANGELOG.ru.md`
- [ ] Зафиксировать формат тегов (`vX.Y.Z`)
- [ ] Описать политику публикации контейнерных образов

## 6. Kubernetes/Operations readiness

- [ ] Проверить legacy и blue/green сценарии деплоя
- [ ] Описать rollback-процедуру
- [ ] Описать требования к кластеру
- [ ] Проверить безопасность и предсказуемость дефолтов chart

## 7. Аудит чувствительных данных

Перед публичным релизом проверить:

- [ ] Нет секретов в истории и отслеживаемых файлах
- [ ] Нет internal-only доменов/кредитов в доках и скриптах
- [ ] Нет персональных данных в примерах и фикстурах

## Команды перед первым публичным тегом

```bash
npm run lint
npm run build
npm run test
helm lint ./charts/warchi
bash -n ./deploy.sh
```
