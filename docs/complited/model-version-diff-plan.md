# Сравнение артефактов модели с предыдущими версиями

## Режимы сравнения

### 1. Табличный diff (список изменений)

Панель/модалка с вкладками «Узлы | Связи | Диаграммы» и списком изменений (added/removed/modified) с путями и подсветкой цветом. Описано в основном плане.

### 2. Визуальный diff (две диаграммы + свойства)

Режим «две диаграммы слева и справа» с подсветкой и панелью свойств выбранного элемента.

---

## Визуальный diff — описание

### Макет

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [Версия слева ▼]    «Архитектура»    [Версия справа ▼]                  │
├──────────────────────────────┬──────────────────────────────────────────┤
│                              │                                          │
│   Канвас ЛЕВАЯ (базовая)     │   Канвас ПРАВАЯ (целевая)                 │
│   • красная обводка/заливка  │   • зелёная обводка/заливка               │
│     — элемент удалён в       │     — элемент добавлен в                   │
│       правой версии          │       правой версии                        │
│   • обычный вид — без        │   • обычный вид — без изменений           │
│     изменений                │     или изменён (жёлтый)                   │
│                              │                                          │
├──────────────────────────────┴──────────────────────────────────────────┤
│  Выбранный элемент: [путь в дереве или «узел X»]                         │
│  Изменённые свойства:                                                    │
│  ┌─────────────────────────────────────────────────────────────────────┐ │
│  │ Свойство     │ Было (слева)        │ Стало (справа)                  │ │
│  │ name         │ Модуль A  [красный] │ Модуль A’ [зелёный]             │ │
│  │ treeOrder    │ 0          [красный] │ 1         [зелёный]             │ │
│  │ documentFileId │ —                 │ file-uuid  [зелёный]             │ │
│  └─────────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────────┘
```

### Логика подсветки на канвасе

- **Слева (базовая версия):**
  - **Красный** — узел/ребро есть в базе, но в целевой версии его нет (удалён) или нет соответствующего по path.
  - Обычный вид — элемент есть в обеих версиях (при изменении свойств можно подсветить жёлтым опционально).

- **Справа (целевая версия):**
  - **Зелёный** — узел/ребро есть только в целевой версии (добавлен).
  - **Жёлтый/оранжевый** — элемент есть в обеих, но изменились свойства (имя, позиция, attrs).
  - Обычный вид — без изменений.

Сопоставление элементов между версиями — по **path в дереве модели** (Root/ModuleA/Component), т.к. id узлов/связей при копировании модели новые.

### Выбор версий

- Сверху два селектора: **«Версия слева»** и **«Версия справа»** — список версий одной модели (тот же `name`), например 1.0.0, 1.1.0, 2.0.0.
- Диаграмма: одна и та же по **имени** (например «Архитектура») в обеих версиях. Если в одной из версий диаграммы с таким именем нет — показывать заглушку или пустой канвас с подписью.

### Панель «Было → Стало» (снизу)

- При **клике по узлу или ребру** на левом или правом канвасе выбирается «логический» элемент (по path).
- Снизу отображается:
  - Путь в дереве (для узла) или «источник → цель» (для связи).
  - Таблица изменённых свойств:
    - колонка «Свойство» (name, treeOrder, documentFileId, поля из attrs и т.д.);
    - колонка «Было (слева)» — значение в базовой версии, подсветка красным для удалённых/старых значений;
    - колонка «Стало (справа)» — значение в целевой версии, подсветка зелёным для новых/изменённых.
  - Если свойство только слева — в «Стало» прочерк; только справа — в «Было» прочерк.

### Технические моменты

1. **Два канваса** — два экземпляра Papirus (или один компонент с двумя контейнерами), каждый получает свои данные: nodes/links/diagrams одной версии + одна выбранная диаграмма по имени.
2. **Подсветка в Papirus** — передавать в рендер карту `modelNodeId → 'added' | 'removed' | 'modified'`. В [ModelDiagramCanvas.vue](src/features/models/components/ModelDiagramCanvas.vue) стиль узлов идёт через `getEffectiveStyle(instance)` и `getBoundComponentStyle(modelNodeId)`. Добавить опциональный слой: если передан `diffStateByModelNodeId`, для узла/ребра переопределять stroke/fill (например красный/зелёный/жёлтый) поверх обычного стиля.
3. **Сопоставление по path** — для левой и правой версии построить `path → nodeId` и `path → linkId`. Для диаграммы: instances ссылаются на modelNodeId; по nodes модели получить path для каждого id; diff по path даёт added/removed/modified для отображения на канвасе и для панели свойств.
4. **Выбор элемента** — при клике на левом канвасе определяем modelNodeId/modelLinkId левой версии → path → находим тот же path на правом канвасе (если есть). Показываем в панели «было/стало» для этого path. И наоборот при клике на правом канвасе.

## Этапы (с учётом визуального diff)

1. **Backend**: API `GET /models/{id}/related-versions` — список версий одной модели.
2. **Утилиты и composable**: построение path, сравнение nodes/links/diagrams, `useModelVersionDiff`.
3. **Табличный diff**: панель со списком изменений (узлы/связи/диаграммы).
4. **Визуальный diff**:
   - Экран/модалка «Визуальное сравнение»: селекторы версий слева/справа, выбор диаграммы по имени.
   - Два канваса с данными двух версий, передача в каждый карты `diffStateByModelNodeId` / `diffStateByModelLinkId`.
   - Расширение ModelDiagramCanvas (или обёртка) для приёма опциональной подсветки diff (красный/зелёный/жёлтый).
   - Нижняя панель: при выборе элемента — таблица «Свойство | Было | Стало» с цветовой подсветкой.

---

## Связь с основным планом

- Тот же API related-versions и та же логика path/diff в `modelDiff.ts` и `useModelVersionDiff`.
- Визуальный diff использует тот же diff-результат (по path), но отображает его на двух канвасах и в панели свойств «было → стало».
