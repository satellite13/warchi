# Перетаскивание узлов из трассировки на диаграмму

## Цель

Дать пользователю возможность поместить на открытую диаграмму любой узел, видимый в
трассировке: корневой или узел раскрытой ветки. Возможность доступна только когда тип
узла поддержан нотацией открытой диаграммы.

## Пользовательский сценарий

1. Пользователь открывает диаграмму и выбирает узел для трассировки.
2. У корня трассировки и у каждого узла в раскрытой ветке отображается drag-handle.
3. Совместимый узел переносится handle-ом на canvas и создаётся в точке отпускания.
4. Для несовместимого с нотацией типа handle остаётся видимым, но выключен и объясняет
   причину в подсказке.
5. Если нотация задаёт несколько подходящих компонентов, после drop открывается
   существующий диалог выбора компонента.

Трассировка не скрывает несовместимые узлы: она всегда отражает граф модели, а не
ограничения конкретной нотации.

## Границы и интеграция

- `ModelTraceabilityPanel` добавляет drag-handle корневому узлу.
- `ModelTraceBranch` добавляет handle вложенным узлам.
- Handle передаёт `application/x-model-node-id` и `text/plain`, как дерево модели.
- `ModelDiagramCanvas` уже принимает этот payload и вызывает
  `addExistingNodeToDiagram`.
- `useModelDiagramInstances` остаётся единственным местом, создающим instance,
  проверяющим нотацию, сохраняющим координаты и регистрирующим undo/redo.

Совместимость вычисляется реактивно из активной диаграммы:

- диаграмма существует и не read-only;
- у диаграммы есть активная нотация;
- для обычного узла найден хотя бы один component этой нотации с тем же `nodeTypeId`;
- каталог `Directory` использует существующий путь размещения заметки.

Проверка в `addExistingNodeToDiagram` сохраняется как окончательная защита на случай
смены нотации или прав доступа между началом drag и drop.

## Ошибки и доступность

- Disabled handle получает объясняющий `title`; drag не стартует.
- Drop вне canvas или на read-only canvas не изменяет диаграмму.
- Совместимость пересчитывается при смене диаграммы, нотации и режима read-only.
- Handle использует существующие семантику и визуальный стиль traceability drag-handle.

## Проверка

1. Unit-тесты проверяют payload, состояние handle для совместимого и несовместимого
   узла, а также root и вложенную ветку.
2. Playwright создаёт compatible trace node, переносит его на canvas и проверяет
   добавленный instance.
3. Playwright проверяет, что несовместимый узел нельзя перетащить и instance не
   создаётся.
4. Существующие тесты `useModelDiagramInstances` подтверждают сохранение позиции,
   диалог выбора компонента и undo/redo.
