# Компактные глубокие ветки трассировки

## Цель

Сохранить читаемость длинных путей трассировки в узкой правой панели без постоянной
горизонтальной прокрутки.

## Поведение

- Каждый новый уровень ветки использует компактный отступ: 8 px слева и 9 px до
  вертикальной линии вместо текущих 11 px и 12 px.
- До четвёртого уровня отступ увеличивается как обычно.
- Начиная с пятого уровня новый горизонтальный отступ не добавляется; вертикальная
  линия и порядок строк продолжают показывать вложенность.
- Панель дерева поддерживает `overflow-x: auto` как запасной путь для экстремально
  длинных строк и нестандартного browser zoom.
- Название остаётся обрезанным с ellipsis в строке, но полный текст доступен через
  `title` и tooltip при hover или keyboard focus.

## Реализация

`ModelTraceBranch` получает depth, вычисляемый из `path`. Его контейнер применяет
класс capped depth для пятого и следующих уровней. CSS отвечает за компактный
отступ и отсутствие добавочного `margin-left` после лимита. `ModelTraceabilityPanel`
разрешает горизонтальную прокрутку контейнера дерева.

## Проверка

Unit-тесты фиксируют передачу depth и capped-класс для ветки глубже четырёх
уровней, а также `title` у сокращённого имени. Вручную проверяется глубокая
ветка в узкой правой панели: имена остаются читаемыми, а крайний контент можно
достичь горизонтальной прокруткой.
