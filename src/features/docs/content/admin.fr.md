# Administration

La section **Administration** est réservée aux comptes avec droits d’administration. Elle regroupe la gestion des utilisateurs et des ressources supprimées.

## Utilisateurs

- liste paginée avec recherche par e-mail ;
- création d’utilisateur avec e-mail, mot de passe et rôle ;
- modification du rôle ;
- suppression d’utilisateur.

## Ressources supprimées

- liste des entités supprimées (soft delete) ;
- restauration ou suppression définitive.

## Accès

Sans droits d’administration, la section n’apparaît pas dans le menu et les routes sont inaccessibles.
