# Администрирование

Разделы администрирования доступны пользователям с правом просмотра админ-панели (`ADMIN_PANEL:VIEW`). На практике это обычно пользователи с ролью **ADMIN**.

## Пользователи

В разделе управления пользователями доступны:

- поиск по email;
- смена роли (`USER` / `ADMIN`);
- активация и блокировка аккаунта;
- редактирование профиля пользователя;
- смена пароля пользователя;
- просмотр и **отзыв API-ключей** пользователя (секрет не показывается; отзыв сразу блокирует MCP и обмен ключа на JWT).

Изменения применяются сразу после подтверждения действия.

## Удалённые сущности

Раздел **Удалённые** показывает удалённые модели и нотации.

Возможности:

- просмотр списка удалённых сущностей;
- **безвозвратное удаление** (permanent delete) по подтверждению.

> Permanent delete нельзя отменить. Рекомендуется выполнять только после проверки, что сущность действительно не нужна.

## Блокировки диаграмм

Раздел **Блокировки диаграмм** (`/admin/diagram-locks`) показывает активные блокировки редактирования холста.

Возможности:

- список активных блокировок с путём «модель / диаграмма» и владельцем блокировки;
- автоматическое обновление списка (live);
- **принудительное снятие** блокировки после подтверждения — когда редактор «завис» или нужно срочно передать холст другому пользователю.

Обычная блокировка при совместной работе описана в разделе [Диаграммы](/docs/diagrams). Админское снятие — исключительный инструмент; после force-release другой пользователь с правом EDIT может снова захватить холст.
