# Администрирование

Разделы администрирования доступны пользователям с правом просмотра админ-панели (`ADMIN_PANEL:VIEW`). На практике это обычно пользователи с ролью **ADMIN**.

## Пользователи

В разделе управления пользователями доступны:

- поиск по email;
- смена роли (`USER` / `ADMIN`);
- активация и блокировка аккаунта;
- редактирование профиля пользователя;
- смена пароля пользователя.

Изменения применяются сразу после подтверждения действия.

## Удалённые сущности

Раздел **Удалённые** показывает удалённые модели и нотации.

Возможности:

- просмотр списка удалённых сущностей;
- **безвозвратное удаление** (permanent delete) по подтверждению.

> Permanent delete нельзя отменить. Рекомендуется выполнять только после проверки, что сущность действительно не нужна.
