# Авторизация и доступ

## Вход в систему

После успешного входа приложение сохраняет токены и открывает рабочие разделы. Если пользователь пытался открыть защищённую страницу до входа, после авторизации выполняется возврат на эту страницу; иначе открывается главная. При неуспешном входе показывается сообщение об ошибке.

## Регистрация

После успешной регистрации создаётся сессия и выполняется переход на главную страницу. Дальнейшие переходы в защищённые разделы доступны без повторного входа, пока сессия активна.

## Роли

- **USER** — работа со своими сущностями и теми, к которым выдан доступ.
- **ADMIN** — дополнительные административные функции (управление пользователями, удалённые сущности).

## Защита маршрутов

- Страницы, требующие авторизации, недоступны без активной сессии.
- Попытка открыть защищённый маршрут без входа перенаправляет на страницу логина.
- Доступ к админ-разделу проверяется по правам (`ADMIN_PANEL:VIEW`) через policy-проверку.

## Обновление сессии

При истечении access-токена клиент пытается обновить сессию через refresh-токен. Если обновление не удалось, сессия очищается и требуется повторный вход.

## Выход

При выходе локальные данные сессии очищаются, и пользователь возвращается к неавторизованному состоянию.
