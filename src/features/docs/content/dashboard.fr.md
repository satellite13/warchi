# Tableau de bord

Le tableau de bord est la page d’accueil après connexion. Il donne un aperçu rapide et des raccourcis vers les tâches courantes.

## Contenu

- **Salutation** et contexte utilisateur.
- **Cartes de statistiques** : modèles, notations, types de nœuds, types de liens.
- **Modèles récents** et **notations récentes** avec lien vers les éditeurs.
- **Actions rapides** (créer un modèle, une notation, ouvrir l’éditeur de types).
- **Fil d’activité** (INSERT / UPDATE / DELETE sur les entités principales).
- **Notes de version** de l’application (extrait du changelog).

## Parcours conseillé

1. Consulter les cartes pour la taille de l’espace de travail.
2. Reprendre le travail depuis modèles/notations récents.
3. Utiliser les actions rapides pour créer des artefacts.
4. Consulter l’activité pour le contexte récent.

## Remarques

- Les cartes sont cliquables et mènent aux sections correspondantes.
- Les dates récentes sont relatives ; les plus anciennes en date absolue.
- Sans section changelog pour la version courante, les notes de version sont vides.
