# Главная страница (Dashboard)

Главная страница — это стартовая точка после входа. Она помогает быстро понять текущее состояние рабочих артефактов и перейти к частым действиям.

## Что отображается

- **Приветствие** и компактные счётчики моделей, нотаций, типов нод и типов связей в одной плашке.
- **Недавние модели** и **недавние диаграммы** — два главных входа, чтобы продолжить работу.
- **Недавние нотации** и **быстрые действия** (создание модели, нотации, **импорт нотации** из JSON-экспорта, переход в редактор типов).
- **Release notes текущей версии** (вытягиваются из changelog).

## Как использовать эффективно

1. Смотрите счётчики в плашке приветствия для общего понимания объёма рабочих артефактов.
2. Продолжайте работу из **недавних моделей** или **недавних диаграмм** — клик по диаграмме открывает редактор модели на этой диаграмме.
3. Используйте блок быстрых действий для старта новых артефактов.
4. Читайте release notes, чтобы узнать об изменениях в текущей версии.

## Практические замечания

- Счётчики в плашке приветствия кликабельны и ведут в соответствующий раздел.
- Дата в списках показывается в относительном формате ("x минут назад"), а для старых записей — как обычная дата.
- Если для текущей версии нет записей в changelog, блок release notes покажет пустое состояние.
