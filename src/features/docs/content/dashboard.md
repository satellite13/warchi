# Главная страница (Dashboard)

Главная страница — это стартовая точка после входа. Она помогает быстро понять текущее состояние рабочих артефактов и перейти к частым действиям.

## Что отображается

- **Приветствие** и контекст пользователя.
- **Карточки статистики** по моделям, нотациям, типам нод и типам связей.
- **Недавние модели** и **недавние нотации** с быстрым переходом в редактор.
- **Быстрые действия** (создание модели, нотации, **импорт нотации** из JSON-экспорта, переход в редактор типов).
- **Лента активности** (INSERT/UPDATE/DELETE по ключевым сущностям).
- **Release notes текущей версии** (вытягиваются из changelog).

## Как использовать эффективно

1. Проверяйте карточки статистики для общего понимания объёма и динамики.
2. Открывайте последние модели/нотации из списков, если продолжаете вчерашнюю работу.
3. Используйте блок быстрых действий для старта новых артефактов.
4. Смотрите ленту активности, чтобы понять, что недавно менялось в системе.

## Практические замечания

- Карточки статистики кликабельны и ведут в соответствующий раздел.
- Дата в списках и ленте показывается в относительном формате ("x минут назад"), а для старых записей — как обычная дата.
- Если для текущей версии нет записей в changelog, блок release notes покажет пустое состояние.
