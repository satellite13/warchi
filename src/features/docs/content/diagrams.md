# Диаграммы

Диаграмма — это графическое представление архитектурной модели. Каждая модель может содержать одну или несколько диаграмм.

## Управление диаграммами

### Создание диаграммы

1. В дереве модели вызовите контекстное меню
2. Выберите **«Создать диаграмму»**
3. Укажите название и выберите нотацию
4. Версия подбирается автоматически — если диаграмма с таким именем уже есть, минорная версия увеличивается

### Переключение между диаграммами

Кликните по нужной диаграмме в дереве модели. Если есть несохранённые изменения, система предложит:

- **Сохранить и переключить** — сохранить текущие изменения, затем открыть новую диаграмму
- **Не сохранять** — отменить изменения и переключиться
- **Отмена** — остаться на текущей диаграмме

### Создание baseline (новой версии диаграммы)

Baseline — это новая версия текущей диаграммы, созданная на основе её текущего состояния.

Как создать baseline:

1. Откройте нужную диаграмму в редакторе модели
2. Вызовите действие создания новой версии диаграммы (baseline)
3. Подтвердите создание — система создаст следующую версию и откроет её

Что важно:

- baseline копирует состав и расположение элементов из исходной диаграммы на момент создания;
- в переключателе версий можно перейти к любой версии диаграммы;
- редактирование доступно только для последней версии, предыдущие версии открываются в режиме только чтение.

#### Когда делать baseline

Рекомендуется создавать baseline перед изменениями, которые могут заметно поменять структуру диаграммы:

- перед авторазмещением большого количества узлов;
- перед массовым редактированием связей или типов отображения;
- перед переработкой группировки и компоновки подсистем;
- перед экспериментами с альтернативным вариантом представления архитектуры.

Пример сценария:

1. Текущая диаграмма согласована и используется как рабочая версия.
2. Нужно попробовать новую компоновку (например, переразбить систему на подсистемы).
3. Создаётся baseline.
4. Изменения выполняются в новой версии.
5. Если вариант удачный — работа продолжается в новой версии; если нет — можно вернуться к предыдущей версии как к опорной.

### Сравнение версий диаграммы

Для активной диаграммы можно открыть экран сравнения её версий.

Как открыть:

1. Откройте диаграмму в редакторе модели.
2. В блоке с версией диаграммы нажмите кнопку **«Сравнить версии диаграммы»** (иконка `compare`).
3. В открывшемся экране выберите версии слева и справа.

Особенности сравнения:

- сравнение выполняется в рамках одного имени диаграммы (например, `Context`, версии `1.0.0` и `1.1.0`);
- обе стороны отображаются в режиме только чтение;
- можно переключать базовую сторону кнопкой **«Переключить базу»**;
- по клику на элемент внизу показывается таблица свойств **было/стало**;
- поддерживается сравнение маршрута связи и её параметров.

Когда использовать:

- после создания baseline, чтобы быстро увидеть фактические изменения;
- перед согласованием новой версии диаграммы с командой;
- перед публикацией ссылки на актуальное визуальное состояние.

### Закрытие и удаление

- **Закрыть** — кнопка на панели инструментов. Диаграмма остаётся в модели, но закрывается из редактора
- **Удалить** — контекстное меню в дереве. Диаграмма будет удалена при сохранении

## Редактор диаграмм

Редактор диаграмм предоставляет графический холст для размещения и соединения компонентов модели.

### Добавление элементов

Элементы можно добавить на диаграмму несколькими способами:

1. **Перетаскивание из палитры** — перетащите тип элемента из палитры на холст
2. **Из дерева модели** — перетащите существующий компонент из дерева модели

### Перемещение и изменение размера

- **Перемещение** — нажмите на элемент и перетащите его в нужное место
- **Изменение размера** — используйте маркеры на краях выделенного элемента
- **Множественное выделение** — зажмите `Ctrl/Cmd` и кликайте по нескольким элементам
- **Рамочное выделение** — `Ctrl/Cmd` + перетаскивание по пустому месту холста

### Соединение элементов

Для создания связи между элементами:

1. Зажмите `Shift` и нажмите на элемент-источник
2. Перетащите линию к элементу-приёмнику
3. Отпустите кнопку мыши на точке соединения приёмника

> Если в нотации не настроены правила связей для выбранных типов элементов, соединение будет недоступно.

### Навигация по холсту

- **Масштабирование** — колесо мыши или жесты трекпада
- **Перемещение холста** — перетаскивание по пустому месту, средняя кнопка мыши или `Пробел` + перетаскивание
- **Вписать в экран** — кнопка на панели инструментов, масштабирует холст под все элементы

### История

| Действие | Описание |
|----------|----------|
| Отменить | Отменить последнее действие (`Ctrl+Z`) |
| Повторить | Повторить отменённое действие (`Ctrl+Y`) |

| Действие | Описание |

| Масштабировать выделение | Подогнать масштаб под выделенные элементы |

### Отображение

| Действие | Описание |

## Настройки диаграммы

Настройки диаграммы управляют поведением редактора для конкретной диаграммы.

Основные настройки:

- **Автолинки в группах** — при переносе компонента внутрь контейнера редактор может автоматически предложить создать или использовать группирующую связь;
- **Привязка к сетке** — помогает ровно выравнивать элементы при перемещении;
- **Сетка / миникарта / линейки** — визуальные помощники для навигации и компоновки;
- **Закрепление точек связей** — фиксирует привязку концов связей при перемещении узлов.

Практические рекомендации:

- включайте привязку к сетке для аккуратной и регулярной раскладки;
- включайте автолинки в группах, если активно используете контейнерные отношения;
- на больших диаграммах используйте миникарту и линейки для более быстрой навигации.

### Экспорт и данные

| Действие | Описание |
|----------|----------|
| Экспорт в PNG | Сохранить диаграмму как растровое изображение PNG |
| Экспорт в SVG | Сохранить диаграмму как векторное изображение SVG |
| Ссылка на картинку | Открыть диалог получения публичной ссылки на превью диаграммы (см. ниже) |
| Просмотр JSON | Показать JSON-представление данных диаграммы |

### Поделиться картинкой диаграммы

Можно получить ссылку на превью диаграммы в виде SVG. Этой ссылкой можно поделиться с коллегами или вставить картинку в Notion, Confluence, чаты, документы — открыть смогут все, у кого есть ссылка, без входа в систему.

**Как получить ссылку:**

1. Откройте нужную диаграмму в редакторе модели.
2. Нажмите **«Ссылка на картинку»** на панели инструментов.
3. В диалоге выберите тип ссылки:
   - **Эта версия диаграммы** — ссылка всегда будет показывать текущий снимок (подходит для фиксации).
   - **Всегда последняя версия по имени** — ссылка будет показывать последнюю сохранённую версию диаграммы с этим именем (картинка обновится после сохранения).
4. Нажмите **«Получить ссылку»** — превью текущего вида загрузится на сервер и будет сформирована ссылка.
5. Нажмите **«Скопировать ссылку»** и вставьте её куда нужно.

Превью также автоматически загружается при сохранении модели, поэтому по ссылке «всегда последняя» после сохранения будет отображаться актуальное состояние.

### Управление

| Действие | Описание |
|----------|----------|
| Закрыть диаграмму | Закрыть текущую диаграмму (без удаления) |
| Сохранить | Сохранить все изменения модели |

## Сохранение

Кнопка **«Сохранить»** на панели инструментов становится активной при наличии несохранённых изменений. Перед сохранением система проверяет, что все обязательные свойства компонентов заполнены. Если валидация не пройдена, будет показано сообщение об ошибке с указанием конкретного элемента и свойства.
