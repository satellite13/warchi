# Диаграммы

Диаграмма — это графическое представление архитектурной модели. Каждая модель может содержать одну или несколько диаграмм.

## Редактор диаграмм

Редактор диаграмм предоставляет графический холст для размещения и соединения компонентов модели.

### Добавление элементов

Элементы можно добавить на диаграмму несколькими способами:

1. **Перетаскивание из палитры** — перетащите тип элемента из палитры на холст
2. **Из дерева модели** — перетащите существующий компонент из дерева модели

### Перемещение и изменение размера

- **Перемещение** — нажмите на элемент и перетащите его в нужное место
- **Изменение размера** — используйте маркеры на краях выделенного элемента
- **Множественное выделение** — зажмите `Shift` и кликните по нескольким элементам

### Соединение элементов

Для создания связи между элементами:

1. Наведите курсор на элемент-источник — появятся точки соединения
2. Нажмите на точку и перетащите линию к элементу-приёмнику
3. Отпустите кнопку мыши на точке соединения приёмника

### Навигация по холсту

- **Масштабирование** — используйте колесо мыши или жесты трекпада
- **Перемещение холста** — зажмите среднюю кнопку мыши или используйте `Пробел` + перетаскивание
- **Сброс масштаба** — используйте кнопку «По размеру» на панели инструментов

## Панель инструментов

На панели инструментов диаграммы доступны следующие действия:

| Действие | Описание |
|----------|----------|
| Приблизить | Увеличить масштаб холста |
| Отдалить | Уменьшить масштаб холста |
| По размеру | Подогнать масштаб под все элементы |
| Удалить | Удалить выделенные элементы |

## Экспорт

Диаграмму можно экспортировать в формате изображения для использования в документации и презентациях.
