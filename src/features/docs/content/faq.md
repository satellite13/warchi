# Часто задаваемые вопросы

## Общие вопросы

### Что такое wArchi?

wArchi — это веб-приложение для управления архитектурными моделями. Оно позволяет создавать визуальные диаграммы, описывать компоненты системы и их взаимосвязи, а также версионировать все артефакты.

### Какие браузеры поддерживаются?

wArchi поддерживает все современные браузеры: Chrome, Firefox, Safari, Edge. Рекомендуется использовать последнюю версию браузера для лучшей производительности.

## Модели

### Как создать новую версию модели?

Откройте модель в редакторе, затем используйте функцию создания новой версии. Новая версия будет содержать копию всех данных из текущей версии.

### Можно ли удалить модель?

Да, модель можно удалить из списка моделей. Обратите внимание, что удаление необратимо и затрагивает все версии модели.

### Как привязать нотацию к модели?

Нотация выбирается при создании модели. Нотация определяет доступные типы элементов и их визуальное представление на диаграммах.

## Нотации

### Зачем нужны нотации?

Нотации определяют «язык» диаграммы — какие типы элементов доступны, как они выглядят и как могут быть связаны. Например, можно создать нотацию для C4-диаграмм или для UML.

### Можно ли использовать одну нотацию для нескольких моделей?

Да, одна нотация может быть использована в нескольких моделях. Изменения в нотации не затрагивают уже существующие модели.

## Диаграммы

### Как экспортировать диаграмму?

Используйте функцию экспорта на панели инструментов диаграммы. Диаграмма будет сохранена в виде изображения.

### Почему элементы не соединяются?

Убедитесь, что в нотации модели настроены правила связей, разрешающие соединение выбранных типов элементов. Если правила не заданы, связи между элементами не будут доступны.

## Версионирование

### Какая система версий используется?

wArchi использует семантическое версионирование (SemVer) в формате `MAJOR.MINOR.PATCH`. Это позволяет отслеживать изменения и поддерживать несколько версий одной сущности.

### Можно ли откатиться к предыдущей версии?

Каждая версия сущности хранится отдельно, поэтому вы можете просматривать и работать с любой из созданных версий.
