# Keyboard Shortcuts

Keyboard shortcuts help speed up work with the diagram editor and other wArchi tools.

## Diagram Editor (Notation / Model)

### Navigation

| Key | Action |
|-----|--------|
| `LMB` + drag on empty space | Pan canvas |
| `Space` + `LMB` + drag | Pan canvas |
| `Middle mouse button` + drag | Pan canvas |
| `Mouse wheel` | Zoom |

### Selection

| Key | Action |
|-----|--------|
| `Click` | Select element |
| `Ctrl/Cmd` + `Click` | Add/remove element from selection |
| `Ctrl/Cmd` + drag on empty space | Marquee selection |

### Connections

| Key | Action |
|-----|--------|
| `+` handle on a node or `Shift` + drag | Create a connection (see also [Diagrams](/docs/diagrams)) |

### Editing

| Key | Action |
|-----|--------|
| `Ctrl/Cmd` + `Z` | Undo last action (geometry, style, properties panel, resize, polyline bends, edge path type) |
| `Ctrl/Cmd` + `Y` | Redo undone action |
| `Ctrl/Cmd` + `Shift` + `Z` | Redo undone action (alternative) |
| `Ctrl/Cmd` + `C` | Copy selected **diagram elements** |
| `Ctrl/Cmd` + `V` | Paste copied **diagram elements** |
| `Double-click` on node/link label | Inline label editing |
| `Enter` in label editor | Save label |
| `Shift` + `Enter` in label editor | New line |
| `Esc` in label editor | Cancel label editing |

> In the model editor, `Ctrl/Cmd` + `C` / `V` are also used for notes in the notes panel context — that clipboard is separate from canvas element copy/paste.

### Deletion

| Key | Action |
|-----|--------|
| `Delete` / `Backspace` (Model Editor) | Delete selected diagram elements |
| — (Notation Editor) | Keyboard deletion disabled, use UI buttons |

## General

| Key | Action |
|-----|--------|
| `Esc` (in property add menu) | Close dropdown menu |

> **Note:** On macOS, use `Cmd` (⌘) instead of `Ctrl`.
