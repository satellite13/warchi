# Raccourcis clavier

Raccourcis dans l’éditeur de diagrammes (Papirus).

## Navigation et zoom

| Raccourci | Action |
|-----------|--------|
| Molette | zoom vers le pointeur |
| `Ctrl` + `+` / `Ctrl` + `-` | zoom avant / arrière |
| `Ctrl` + `0` | zoom 100 % |
| `Ctrl` + `1` | ajuster à la fenêtre |
| `Espace` + glisser | panoramique |
| Flèches | déplacer la sélection |
| `Shift` + flèches | déplacer par pas plus grands |

## Sélection

| Raccourci | Action |
|-----------|--------|
| `Ctrl` + clic | ajouter / retirer de la sélection |
| `Shift` + clic | sélection par plage |
| `Ctrl` + `A` | tout sélectionner |
| `Échap` | désélectionner |

## Édition

| Raccourci | Action |
|-----------|--------|
| `Ctrl` + `Z` | annuler |
| `Ctrl` + `Shift` + `Z` / `Ctrl` + `Y` | rétablir |
| `Suppr` / `Retour arrière` | supprimer la sélection |
| `Ctrl` + `D` | dupliquer |
| `Ctrl` + `G` | grouper |
| `Ctrl` + `Shift` + `G` | dissocier |

## Alignement

| Raccourci | Action |
|-----------|--------|
| `Ctrl` + `Shift` + `L` | aligner à gauche |
| `Ctrl` + `Shift` + `R` | aligner à droite |
| `Ctrl` + `Shift` + `T` | aligner en haut |
| `Ctrl` + `Shift` + `B` | aligner en bas |
| `Ctrl` + `Shift` + `H` | centrer horizontalement |
| `Ctrl` + `Shift` + `V` | centrer verticalement |

## Grille et repères

| Raccourci | Action |
|-----------|--------|
| `Ctrl` + `;` | activer / désactiver la grille |
| `Ctrl` + `'` | activer / désactiver les repères |

## Export

| Raccourci | Action |
|-----------|--------|
| `Ctrl` + `Shift` + `E` | exporter en PNG |
| `Ctrl` + `Shift` + `S` | exporter en SVG |

## Aide

| Raccourci | Action |
|-----------|--------|
| `?` | afficher / masquer l’aide des raccourcis |

## Remarques

- Sur macOS, `Ctrl` peut correspondre à `Cmd` selon le navigateur.
- Certains raccourcis peuvent être interceptés par le navigateur ou l’OS.
