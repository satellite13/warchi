# Горячие клавиши

Горячие клавиши позволяют ускорить работу с редактором диаграмм и другими инструментами wArchi.

## Редактор диаграмм (Notation / Model)

### Навигация

| Клавиша | Действие |
|---------|----------|
| `ЛКМ` + перетаскивание по пустому месту | Перемещение холста |
| `Пробел` + `ЛКМ` + перетаскивание | Перемещение холста |
| `Средняя кнопка мыши` + перетаскивание | Перемещение холста |
| `Колесо мыши` | Масштабирование |

### Выделение

| Клавиша | Действие |
|---------|----------|
| `Клик` | Выделить элемент |
| `Ctrl/Cmd` + `Клик` | Добавить/убрать элемент из выделения |
| `Ctrl/Cmd` + перетаскивание по пустому месту | Рамочное выделение |

### Редактирование

| Клавиша | Действие |
|---------|----------|
| `Ctrl/Cmd` + `Z` | Отменить последнее действие |
| `Ctrl/Cmd` + `Y` | Повторить отменённое действие |
| `Ctrl/Cmd` + `Shift` + `Z` | Повторить отменённое действие (альтернатива) |
| `Ctrl/Cmd` + `C` | Копировать выделенные элементы |
| `Ctrl/Cmd` + `V` | Вставить скопированные элементы |
| `Двойной клик` по метке узла/связи | Встроенное редактирование текста метки |
| `Enter` в редакторе метки | Сохранить метку |
| `Shift` + `Enter` в редакторе метки | Новая строка |
| `Esc` в редакторе метки | Отменить редактирование метки |

### Удаление

| Клавиша | Действие |
|---------|----------|
| `Delete` / `Backspace` (Model Editor) | Удалить выбранные элементы диаграммы |
| — (Notation Editor) | Удаление с клавиатуры отключено, используйте UI-кнопки |

## Общие

| Клавиша | Действие |
|---------|----------|
| `Esc` (в меню добавления свойств) | Закрыть выпадающее меню |

> **Примечание:** На macOS вместо `Ctrl` используется клавиша `Cmd` (`⌘`).
