# Горячие клавиши

Горячие клавиши позволяют ускорить работу с редактором диаграмм и другими инструментами wArchi.

## Редактор диаграмм

### Навигация

| Клавиша | Действие |
|---------|----------|
| `Пробел` + перетаскивание | Перемещение холста |
| `Колесо мыши` | Масштабирование |
| `Ctrl` + `0` | Сбросить масштаб (100%) |
| `Ctrl` + `1` | Подогнать по размеру |

### Выделение

| Клавиша | Действие |
|---------|----------|
| `Клик` | Выделить элемент |
| `Shift` + `Клик` | Добавить к выделению |
| `Ctrl` + `A` | Выделить все элементы |
| `Escape` | Снять выделение |

### Редактирование

| Клавиша | Действие |
|---------|----------|
| `Delete` / `Backspace` | Удалить выделенные элементы |
| `Ctrl` + `Z` | Отменить последнее действие |
| `Ctrl` + `Shift` + `Z` | Повторить отменённое действие |
| `Ctrl` + `C` | Копировать выделенные элементы |
| `Ctrl` + `V` | Вставить скопированные элементы |

## Общие

| Клавиша | Действие |
|---------|----------|
| `Ctrl` + `S` | Сохранить изменения |
| `Ctrl` + `F` | Поиск |

> **Примечание:** На macOS вместо `Ctrl` используется клавиша `Cmd` (`⌘`).
