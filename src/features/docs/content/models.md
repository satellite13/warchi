# Работа с моделями

Модели — это основные сущности в wArchi. Каждая модель представляет собой архитектурное описание системы, состоящее из диаграмм, компонентов и связей.

## Список моделей

На странице **Модели** отображается список всех созданных моделей. Модели группируются по имени — каждая группа может содержать несколько версий.

### Создание модели

1. Нажмите кнопку **«Создать»** в заголовке списка
2. Введите название модели
3. Выберите нотацию, которая будет использоваться в модели
4. Нажмите **«Создать»** для подтверждения

Новая модель создаётся с версией `1.0.0`.

### Версионирование

Модели поддерживают семантическое версионирование (SemVer):

- **Major** (основная) — несовместимые изменения архитектуры
- **Minor** (минорная) — добавление новых элементов с сохранением совместимости
- **Patch** (патч) — исправления и мелкие правки

Вы можете создать новую версию модели на основе существующей.

## Редактор модели

Редактор модели включает несколько областей:

### Дерево модели

В левой панели отображается иерархическая структура модели:

- **Компоненты** — элементы архитектуры (сервисы, модули, базы данных и т.д.)
- **Связи** — отношения между компонентами

Вы можете добавлять, переименовывать и удалять элементы через контекстное меню.

### Палитра

Панель палитры содержит доступные типы элементов, определённые в нотации модели. Перетащите элемент из палитры на диаграмму для добавления.

### Свойства

При выборе элемента в дереве или на диаграмме отображается панель свойств, где можно редактировать атрибуты элемента.

## Удаление модели

Для удаления модели используйте кнопку удаления в списке моделей. Будьте осторожны — удаление необратимо.
