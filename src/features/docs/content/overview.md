# Обзор системы

**wArchi** — веб-приложение для управления архитектурными моделями, нотациями и типами. Система поддерживает полный цикл: от проектирования типов и правил связей до построения диаграмм, версионирования и совместной работы.

## Основные возможности

- **Модели** — создание и редактирование архитектурных моделей с поддержкой версий
- **Нотации** — визуальная настройка компонентов и связей (формы, стили, поведение)
- **Диаграммы** — графический редактор с инструментами навигации, авторазмещением, экспортом PNG/SVG и просмотром JSON
- **Baseline диаграмм** — создание новой версии диаграммы на основе текущего состояния с переключением между версиями
- **Типы** — управление типами нод и связей, включая пользовательские и системные свойства
- **Пользовательские свойства** — поддержка типов `string`, `number`, `boolean`, `enum`, дефолтов и валидации
- **ACL-доступы** — шаринг моделей, нотаций и типов с уровнями `VIEW`/`EDIT`

## Структура приложения

Приложение состоит из нескольких основных разделов, доступных через навигационное меню:

| Раздел | Описание |
|--------|----------|
| Главная | Дашборд со статистикой, последними действиями, быстрыми действиями и описанием текущей версии |
| Модели | Список моделей, редактор модели, работа с диаграммами и версиями baseline |
| Нотации | Список нотаций, визуальный редактор компонентов/связей и правил связей |
| Типы | Редактор типов нод и связей, настройка полей (`icon`, `defaultDirectoryPath`, custom properties) |
| Документация | Данный раздел справки |

## Права доступа и шаринг

В системе используется ролевая модель и ACL-доступы:

- **ADMIN** — полный доступ ко всем ресурсам.
- **USER** — работает со своими ресурсами и с теми, к которым выдан доступ.
- Шаринг top-level сущностей (модели, нотации, типы) поддерживает два уровня:
  - **VIEW** — просмотр;
  - **EDIT** — редактирование.

В карточках и списках отображается фактический уровень доступа к ресурсу.

## Начало работы

1. Авторизуйтесь в системе через страницу входа
2. На главной странице вы увидите обзор ваших моделей и нотаций
3. Перейдите в раздел **Типы** и создайте типы нод/связей, при необходимости добавьте пользовательские и системные свойства
4. Создайте **нотацию**, добавьте компоненты и связи на основе типов, настройте стили и правила связей
5. Создайте **модель**, выберите нотацию и постройте диаграмму, перетаскивая элементы из палитры
6. Перед крупными изменениями диаграммы создавайте **baseline**, чтобы сохранить стабильную версию и безопасно экспериментировать
