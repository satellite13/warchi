# Обзор системы

**wArchi** — это веб-приложение для управления архитектурными моделями и нотациями. Система позволяет создавать, редактировать и версионировать доменные модели с поддержкой компонентов, связей и пользовательских свойств.

## Основные возможности

- **Модели** — создание и редактирование архитектурных моделей с поддержкой версионирования
- **Нотации** — визуальное определение нотаций для отображения элементов на диаграммах
- **Диаграммы** — графический редактор для построения и редактирования диаграмм с экспортом в PNG и SVG
- **Типы** — управление типами нод и связей с пользовательскими свойствами
- **Версионирование** — семантическое версионирование всех сущностей (SemVer)
- **Доступы** — ACL-шаринг ресурсов между пользователями с правами просмотра и редактирования

## Структура приложения

Приложение состоит из нескольких основных разделов, доступных через навигационное меню:

| Раздел | Описание |
|--------|----------|
| Главная | Дашборд со статистикой, последними действиями, быстрыми действиями и описанием текущей версии |
| Модели | Список моделей и редактор моделей с диаграммами |
| Нотации | Список нотаций и визуальный редактор нотаций |
| Типы | Редактор типов нод и связей |
| Документация | Данный раздел справки |

## Права доступа и шаринг

В системе используется ролевая модель и ACL-доступы:

- **ADMIN** — полный доступ ко всем ресурсам.
- **USER** — работает со своими ресурсами и с теми, к которым выдан доступ.
- Шаринг top-level сущностей (модели, нотации, типы) поддерживает два уровня:
  - **VIEW** — просмотр;
  - **EDIT** — редактирование.

В карточках и списках отображается фактический уровень доступа к ресурсу.

## Начало работы

1. Авторизуйтесь в системе через страницу входа
2. На главной странице вы увидите обзор ваших моделей и нотаций
3. Перейдите в раздел **Типы** и создайте типы нод и связей для вашей архитектуры
4. Создайте **нотацию**, добавив компоненты и связи на основе типов и настроив их визуальные стили
5. Создайте **модель**, выбрав нотацию, и постройте диаграмму, перетаскивая элементы из палитры
