# Profil utilisateur

La section **Profil** permet de gérer les données personnelles utilisées dans l’interface et les métadonnées.

## Champs disponibles

- Prénom
- Nom
- Deuxième prénom
- Fonction

## Enregistrement

- Le bouton **Enregistrer** n’est actif que si des données ont changé.
- Prénom et nom sont obligatoires.
- Un message de succès s’affiche après mise à jour.

## Cas d’usage

- harmoniser le nom affiché avec les conventions d’équipe ;
- tenir à jour la fonction / intitulé de poste ;
- corriger les données sans intervention administrateur.
