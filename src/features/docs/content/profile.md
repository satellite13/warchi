# Профиль пользователя

В разделе **Профиль** пользователь редактирует персональные данные, используемые в интерфейсе и метаданных.

## Доступные поля

- Имя
- Фамилия
- Отчество
- Должность

## Сохранение

- Кнопка **Сохранить** активируется только при наличии изменений.
- Для сохранения обязательны имя и фамилия.
- После успешного сохранения отображается подтверждение.

## Когда это полезно

- привести отображаемое имя к командному формату;
- актуализировать должность для карточек/метаданных;
- исправить персональные данные без участия администратора.
