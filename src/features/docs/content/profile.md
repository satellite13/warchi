# Профиль пользователя

В разделе **Профиль** пользователь редактирует персональные данные, используемые в интерфейсе и метаданных, и управляет API-ключами для MCP.

## Доступные поля

- Имя
- Фамилия
- Отчество
- Должность

## Сохранение

- Кнопка **Сохранить** активируется только при наличии изменений.
- Для сохранения обязательны имя и фамилия.
- После успешного сохранения отображается подтверждение.

## API-ключи

Ключи нужны для удалённого MCP-сервера wArchi и других non-browser клиентов.

- **Область доступа** при создании:
  - **Все доступные модели** — глобальные права чтения и/или записи моделей, которые уже видны вашему аккаунту;
  - **Выбранные модели** — для каждой модели отдельно чтение и/или запись (поиск и мультивыбор в форме). Запись подразумевает чтение.
- После создания scopes и список моделей **нельзя изменить** — переименуйте ключ или отзовите и создайте новый.
- Секрет `warchi_ak_…` показывается **один раз** — сохраните его в настройках MCP-клиента.
- Отзыв ключа сразу блокирует обмен на JWT (`/auth/api-keys/exchange`).
- Администратор может просмотреть метаданные ключей пользователя и отозвать их из карточки пользователя (секрет не показывается).

## Когда это полезно

- привести отображаемое имя к командному формату;
- актуализировать должность для карточек/метаданных;
- исправить персональные данные без участия администратора;
- подключить Cursor/агента к моделям через MCP.
