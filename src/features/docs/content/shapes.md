# Формы

Раздел **Формы** предназначен для управления пользовательскими контурами узлов, которые затем можно использовать в нотациях как **кастомную форму**.

## Для чего нужны формы

- создать фирменный или предметно-специфичный контур, которого нет среди встроенных фигур;
- переиспользовать один и тот же контур в нескольких нотациях;
- централизованно обновлять контур без ручной правки каждой нотации.

## Структура раздела

Страница состоит из двух частей:

- **Левая панель** — список форм, поиск и кнопка создания;
- **Правая панель** — редактор выбранной формы.

## Поля формы

У формы доступны два основных поля:

- **Название** — отображается в списках и при выборе формы в редакторе нотации;
- **Контур (outline)** — геометрия формы, редактируется визуально.

## Редактирование контура

В редакторе контура доступны базовые действия:

- перетащить точку, чтобы изменить форму;
- двойной клик по ребру — добавить точку;
- двойной клик по точке — удалить точку (минимум 3 точки);
- масштаб: `+`, `-`, и сброс `1:1`.

## Создание и удаление

### Создание формы

1. Нажмите **«Добавить форму»**.
2. Система создаст новую форму с базовым прямоугольным контуром.
3. Измените название и контур.
4. Нажмите **«Сохранить»**.

### Удаление формы

1. Выберите форму.
2. Нажмите **«Удалить»**.
3. Подтвердите действие в диалоге.

## Права доступа

- Если у пользователя нет прав редактирования, форма открывается в режиме просмотра.
- В этом режиме поля блокируются, а кнопки сохранения/удаления недоступны.

## Использование в нотации

После сохранения форму можно выбрать в панели стиля компонента:

1. Откройте редактор нотации.
2. Выберите компонент.
3. В секции формы установите тип **Кастомная форма**.
4. Выберите нужную форму из списка.
