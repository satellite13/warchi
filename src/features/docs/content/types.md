# Типы нод и связей

Типы — это глобальные сущности, определяющие структуру элементов архитектурных моделей. Тип задаёт **название** элемента и набор **пользовательских свойств**. Визуальное оформление (форма, цвет, иконка) настраивается отдельно в компонентах нотации, привязанных к типу.

Управление типами осуществляется через раздел **Типы** в навигационном меню.

## Типы нод

Типы нод описывают компоненты архитектуры — сервисы, модули, базы данных, интерфейсы и другие элементы.

### Свойства типа ноды

| Свойство | Описание |
|----------|----------|
| Название | Уникальное имя типа |

### Создание типа ноды

1. Перейдите в раздел **Типы**
2. В панели типов нод нажмите **«Добавить»**
3. Введите название типа
4. Сохраните изменения

### Удаление типа ноды

Тип можно удалить через контекстное меню или кнопку удаления. Перед удалением убедитесь, что тип не используется в нотациях и моделях.

## Типы связей

Типы связей описывают отношения между компонентами — зависимости, потоки данных, наследование и т.д.

### Свойства типа связи

| Свойство | Описание |
|----------|----------|
| Название | Уникальное имя типа связи |

### Создание типа связи

1. Перейдите в раздел **Типы**
2. В панели типов связей нажмите **«Добавить»**
3. Введите название типа связи
4. Сохраните изменения

## Пользовательские свойства

К типам нод и связей можно добавлять пользовательские свойства. Эти свойства будут доступны при редактировании экземпляров в модели.

Поддерживаемые типы свойств:

- **Текст** — строковое значение
- **Число** — числовое значение
- **Перечисление (enum)** — выбор из заданного списка значений

Для каждого свойства можно указать:

- Имя свойства
- Тип данных
- Значение по умолчанию
- Обязательность заполнения

> При добавлении нового обязательного свойства с дефолтным значением, существующие экземпляры в моделях автоматически получат значение по умолчанию при следующем открытии модели.

## Правила связей

Правила связей определяют, какие типы нод могут быть соединены определёнными типами связей. Это позволяет обеспечить корректность архитектурных моделей.

### Настройка правил

Для каждого правила указываются:

- **Связь** — тип связи (relation), к которому применяется правило
- **Источник** — допустимый тип компонента-источника
- **Приёмник** — допустимый тип компонента-приёмника

## Связь типов и нотаций

Типы — глобальные сущности, доступные во всех нотациях. В редакторе нотаций типы используются для создания **компонентов** и **связей** нотации. Компонент нотации привязывается к типу и добавляет визуальное оформление: форму, цвет, иконку, стиль линии и другие параметры отображения на диаграмме.
