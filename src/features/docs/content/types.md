# Типы нод и связей

Типы определяют структуру и визуальное представление элементов, используемых в архитектурных моделях. Управление типами осуществляется через раздел **Типы** в навигационном меню.

## Типы нод

Типы нод описывают компоненты архитектуры — сервисы, модули, базы данных, интерфейсы и другие элементы.

### Свойства типа ноды

| Свойство | Описание |
|----------|----------|
| Название | Уникальное имя типа |
| Описание | Текстовое описание назначения |
| Форма | Визуальная форма на диаграмме |
| Цвет | Цвет заливки и обводки |
| Иконка | Иконка, отображаемая на элементе |

### Создание типа ноды

1. Перейдите в раздел **Типы**
2. В панели типов нод нажмите **«Добавить»**
3. Заполните свойства типа
4. Сохраните изменения

## Типы связей

Типы связей описывают отношения между компонентами — зависимости, потоки данных, наследование и т.д.

### Свойства типа связи

| Свойство | Описание |
|----------|----------|
| Название | Уникальное имя типа связи |
| Описание | Текстовое описание |
| Стиль линии | Сплошная, пунктирная или точечная |
| Стрелка | Тип стрелки на конце связи |
| Цвет | Цвет линии связи |

### Создание типа связи

1. Перейдите в раздел **Типы**
2. В панели типов связей нажмите **«Добавить»**
3. Заполните свойства типа связи
4. Сохраните изменения

## Правила связей

Правила связей определяют, какие типы нод могут быть соединены определёнными типами связей. Это позволяет обеспечить корректность архитектурных моделей.

### Настройка правил

Для каждого типа связи можно указать:

- **Источник** — допустимые типы нод-источников
- **Приёмник** — допустимые типы нод-приёмников
- **Кратность** — ограничения на количество связей
