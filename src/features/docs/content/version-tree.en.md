# Version Tree

Models and notations support a **version tree** view that shows lineage between versions and branch structure.

## What the tree shows

- linear version chains;
- branch points (independent development lines);
- root versions (created from scratch or with no visible source in current data).

## Where to open

- in the models catalog;
- in the notations catalog.

The action is typically available from an entity card menu/button for version lineage.

## Why it is useful

- understand where the current version came from;
- choose the right baseline for comparison;
- detect parallel branches and coordinate next steps.
