# Arbre des versions

Les modèles et notations proposent une vue **arbre des versions** montrant la filiation entre versions et la structure des branches.

## Contenu de l’arbre

- chaînes de versions linéaires ;
- points de branchement (lignes de développement parallèles) ;
- versions racines (créées depuis zéro ou sans source visible dans les données).

## Où l’ouvrir

- dans le catalogue des modèles ;
- dans le catalogue des notations.

L’action est en général disponible depuis le menu ou le bouton de la carte (lignée de versions).

## Utilité

- comprendre l’origine de la version courante ;
- choisir une bonne base pour la comparaison ;
- repérer les branches parallèles et coordonner la suite.
