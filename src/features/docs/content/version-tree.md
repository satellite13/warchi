# Дерево версий

Для моделей и нотаций доступен просмотр **дерева версий**: от какой версии была создана новая и как формировались ветки.

## Что показывает дерево

- линейные цепочки версий;
- развилки (если есть независимые ветки развития);
- корневые версии (созданные "с нуля" или без источника в текущей выборке).

## Где открыть

- в каталоге моделей;
- в каталоге нотаций.

Обычно действие доступно из карточки сущности через меню/кнопку просмотра версионного дерева.

## Когда использовать

- понять происхождение текущей версии;
- выбрать корректную базу для сравнения;
- обнаружить параллельные ветки и договориться о дальнейшем развитии.
