# Wiki

The **Wiki** section aggregates documents linked to domain entities: models, notations, types, shapes, diagrams, and nodes.

## Core behavior

- documents are grouped by entity type;
- list items include contextual labels (including parent context when available);
- selected documents are rendered as Markdown in read mode.

## How to navigate

1. Select an entity group in the left sidebar (localized headings: model, node type, link type, notation, component, relation, shape, diagram, node, unscoped). Groups can be collapsed.
2. Open a document from the group list.
3. Read the content in the right panel.

## Where documents come from

Documents are created via contextual actions in editors (model, diagram, node, notation, component, relation, type, shape). After save, they become visible in Wiki. The Wiki section is read-only.

## Recommended use

- store architecture conventions close to actual entities;
- document diagram intent and key node semantics;
- use Wiki as a single entry point for contextual project knowledge.
